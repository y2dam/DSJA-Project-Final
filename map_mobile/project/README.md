# Financial Health Dashboard

밝은 톤 UI로 제작된 금융 대시보드 페이지입니다.

## 폴더 구조

```
.
├── index.html      # 대시보드 메인 페이지
└── fonts/          # 페이지에서 사용하는 웹폰트
    ├── A2G-Medium.ttf
    ├── A2G-SemiBold.ttf
    ├── Freesentation-Regular.ttf
    └── NotoSansKR-Light.ttf
```

## 로컬에서 보기

`index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## GitHub Pages로 배포하기

1. 저장소 Settings → Pages 이동
2. Source를 `Deploy from a branch`로 설정, Branch는 `main` / `(root)` 선택
3. 저장 후 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 확인 가능
